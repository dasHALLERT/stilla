    Wie stilla verschlüsselt

    Für alle, die (zu Recht) fragen: Niemand außer dem Empfänger kann deine Nachrichten lesen — auch die Server nicht.

    1. Dein Gerät erzeugt beim Anlegen eigene Schlüssel. Der private Schlüssel verlässt dein Gerät nie.
    2. Nachrichten werden auf deinem Gerät verschlüsselt, bevor sie rausgehen. Auf dem Server liegt nur ein verschlüsselter Umschlag — {salt, iv, tag, ciphertext}, Datenmüll ohne Schlüssel.
    3. Nur der Empfänger entschlüsselt mit seinem privaten Schlüssel. Der Server kann es mathematisch nicht.
    4. Gebaut mit geprüften Standard-Bausteinen — X25519, AES-256-GCM, Ed25519 — keine selbstgebaute Kryptografie.

    Ehrlich bleibt: „unhackbar" gibt es nicht. Was stimmt — die Server lesen nichts mit. Vor dem echten Start durchläuft stilla eine unabhängige Sicherheitsprüfung.

    Wofür stilla steht

    Keine Nummer, keine SIM

    Du bekommst eine eigene Kennung — ohne Handynummer, unabhängig vom Mobilfunk.

    Nichts bleibt liegen

    Server speichern keine lesbaren Daten. Nachrichten werden nach Zustellung gelöscht.

    Quelloffen

    Der Code ist offen einsehbar. Vertrauen durch Nachprüfbarkeit, nicht durch Versprechen.
